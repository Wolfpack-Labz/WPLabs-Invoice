Printer offline? How to fix it on Windows and Mac

Work through an offline printer message with checks for cables, Wi-Fi, Windows and Mac print queues, and the right next step before reinstalling.

By Wolfpack Labs · October 30, 2026 · 4 min read

What an offline printer message means

An “offline” label means the computer cannot currently use the selected printer connection. It does not, by itself, tell you whether the printer, network, cable, or saved printer entry is responsible.

Quick answer

Check the printer's own screen, confirm the selected printer and connection, and inspect the print queue. After each change, send one short test document so you can tell what helped.

Before starting, note the printer model and whether it connects by USB, Wi-Fi, Ethernet, or a workplace print server. “Wireless printer” is only part of the description; the connection it uses today matters.

1. Start at the printer itself

Wake the printer and check its display for a paper jam, open cover, supply warning, or setup message. Load the requested paper size and follow the model's instructions for any displayed error. Microsoft's printing troubleshooting guide includes these physical checks.

If the printer provides a built-in status or test page, try that from its own controls. A successful page is evidence that the printer can produce output independently of your document. It does not prove that the computer's connection is working.

Keep this distinction in your notes: “Printer's test page works; laptop job stays queued.” That is more useful than “nothing prints” when you ask for help.

2. Confirm how the computer reaches it

USB: reseat both ends of the cable. If you use a hub or dock, try a compatible direct connection to the computer. Our USB-C cable guide explains why matching connectors do not guarantee matching capabilities.

Home Wi-Fi: check the printer's network screen and the computer's selected network. Replacing a router or changing a Wi-Fi password can leave the printer needing setup again. Use its manufacturer's instructions to reconnect it.

Workplace printer: confirm the queue name with IT, including any required company network or VPN connection. A shared print server may have its own problem even when the printer is powered on.

If websites also fail, first use our connected-without-internet guide to understand the wider connection problem. Report whether other people can print to the same device.

3. Check the Windows 11 print queue

  1. Open Settings → Bluetooth & devices → Printers & scanners.
  2. Select the intended printer and choose Open print queue.
  3. Check for an older failed job. Cancel your own stuck job if appropriate, then send one small document again.
  4. If the connection still shows offline, run the Printer troubleshooter in Get Help.

Microsoft's offline printer guide covers restarting the printer and later repair steps. For a home printer, follow its power-cycle instructions when no job is active. Coordinate a shared printer restart with its owner.

Look closely at the selected destination in the app's print dialog. A saved PDF destination or an old copy of a printer entry may explain why the expected device receives nothing. Avoid sending the same confidential document repeatedly while testing.

4. Check the Mac print queue

Open System Settings → Printers & Scanners, select the intended printer, and open its queue. Print Center can show whether the queue or an individual job is paused. Resume it when appropriate, or remove your own failed job before trying again.

Apple's printing troubleshooting guide for Mac explains the queue controls and suggests testing another app. Try a short TextEdit document if one PDF or browser page is the only thing that fails.

Resetting the entire Mac printing system removes printers and presets. Keep that as a later, deliberate step after simpler checks and after confirming how you will add your printers again.

5. Use one small test to narrow the problem

What to include in your support request
Test result Useful next check
The printer cannot print its own status page Follow the error on the printer or contact its manufacturer.
Another computer prints successfully Compare the affected computer's queue and connection.
A short text document prints; one file fails Investigate that file or application.
Several users fail on the same shared printer Ask IT to check the shared connection or print server.

If reinstallation becomes necessary, use the operating system's printer setup or the exact manufacturer's support page. Record the printer model, OS version, queue name, and error first. That information also helps support choose the right driver.

Common questions

Why did restarting the laptop not fix it?

The computer is one part of the path. Your next test should check the printer's display, its connection, and whether a second computer can print. Those observations help identify which part still needs attention.

Can I get a document ready while printing is unavailable?

Keep the original file and prepare a PDF if your application supports it. For paper records, our phone-to-PDF guide offers another way to create a readable copy. Check the recipient's requirements before substituting a digital document.
