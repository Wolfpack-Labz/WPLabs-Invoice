OneDrive Not Syncing? How to Fix Stuck Files and Sync Errors in Windows 11

Troubleshoot OneDrive stuck on Processing changes, paused sync, file conflicts, account errors and safe reset steps in Windows 11.

Start here: is OneDrive paused, blocked, or processing?

OneDrive can look healthy in File Explorer while a recent edit has not reached the cloud. The problem might involve a paused sync, a file-name conflict, a full account, a sign-in requirement, or an application stuck on “Processing changes.” The aim is to find which file or condition is blocking the queue before resetting anything.

Quick answer: Open the OneDrive cloud icon beside the clock, read its status and any error details, check the same file in OneDrive on the web, then resolve the named issue. Reset the app only after simpler checks fail.

Before you begin, make a separate backup of any local-only files and unfinished changes. Do not delete a conflicted file simply to clear a red X. On work or school accounts, follow your organization's retention and sharing policies.

Step 1: Read the status icon and identify the account

  1. Select the white or blue OneDrive cloud in the Windows notification area. Open Show hidden icons if you cannot see it.
  2. Check whether the app says Paused, Sign in, Processing changes, Sync pending, or displays a specific file error.
  3. If you have both personal and business accounts, confirm which icon and folder contain the failing file.
  4. Note the file name, folder path, and last-known successful sync time.

A circular sync icon means work is in progress, not proof that every file has uploaded. Microsoft's OneDrive icon reference explains the status indicators.

Step 2: Compare the local file with the cloud copy

  1. Sign in to OneDrive on the web for a personal account, or open OneDrive from your organization's Microsoft 365 portal.
  2. Find the affected file and compare its modification time and contents with the local version.
  3. If the web copy is current but File Explorer is not, investigate download/sync to this PC. If the local copy is newer, focus on upload.
  4. Check the account's available storage. A full cloud quota can prevent new uploads.

Do not move or delete files as a first test. Sync services may propagate the change to other devices. If the file is business-critical, save a separate copy outside a synced folder first.

Step 3: Resolve a specific file conflict

Open the OneDrive error list and act on the exact file reported:

  • File open in another program: Save and close the document on all devices you control, then retry.
  • Invalid or conflicting name: Rename only the problem file according to the error shown; avoid special characters restricted by your organization's setup.
  • Too little cloud storage: Free space through the account's approved storage options or request a quota review.
  • Access denied / read-only library: Check whether permissions changed; ask the library owner instead of repeatedly re-signing in.
  • A library has too many changes: Allow time for a large initial sync and review Microsoft's “Processing changes” guidance.

Avoid mass-renaming an entire shared folder. Fix one blocking item, then check whether the queue moves.

Step 4: Pause, resume, and restart the sync client

  1. Select the OneDrive cloud icon, open the Settings/help menu, and choose Pause syncing if available.
  2. Resume synchronization from the same menu. A paused cloud icon should clear.
  3. If the status remains stuck, quit OneDrive from its menu.
  4. Open Start, search for OneDrive, launch the app, and check the icon again.
  5. Test with a small new, non-sensitive text file in a folder you own. Verify it appears on the web, then delete that test file from the same account.

Pause/resume is supported by Microsoft's OneDrive sync guidance. A successful test in one folder does not automatically prove that another shared library has correct permissions.

Step 5: Reset OneDrive only if the client is stuck

A reset can rebuild the app's sync state; it may trigger a full reconciliation and take time for large folders. First confirm important local edits are backed up. On a managed computer, ask IT before resetting a work account.

  1. Press Windows + R.
  2. Enter the command below and select OK:
%localappdata%\Microsoft\OneDrive\OneDrive.exe /reset
  1. If Windows cannot find that path, use the alternate reset commands provided on the official Reset OneDrive page for your installed version. Do not download random “sync repair” scripts.
  2. If the cloud icon does not return, launch OneDrive from Start.
  3. Check folder selection, sign-in, and sync status after the reset completes.

Resetting is not a substitute for fixing permission errors or a full storage quota.

Step 6: Confirm synchronization in both directions

Edit a harmless test document on the PC and confirm the update appears on the web. Then make a small change to a different test file in the browser and verify it reaches the PC. If only one direction fails, note the direction, exact error, and affected location.

If multiple users report the same work-library issue, ask the Microsoft 365 administrator to review service health, site permissions, and library restrictions. Do not unlink a work account or reinstall the client without understanding organizational policy.

Frequently asked questions

Will resetting OneDrive delete cloud files?

A normal client reset is intended to rebuild syncing, not erase cloud data. Still, unsynced local edits may be vulnerable to mistakes during troubleshooting. Back them up separately first.

Why do I see a green check but my coworker sees an older version?

You may be viewing a different account, a shortcut to a shared library, or a file that has not propagated as expected. Compare the full path, owner, and version history rather than relying on the icon alone.

Should I uninstall OneDrive to fix one file?

Usually not. Isolate the individual error, try pause/resume, and consider a documented reset before reinstalling.
