Why is my laptop so slow? A practical Windows and Mac checklist

Separate a slow computer from a slow internet connection, check busy apps and storage, and try simple fixes before paying for an upgrade.

Find out what is actually slow

“My laptop is slow” can mean several different things: it takes ages to start, one app freezes, websites load slowly, or typing lags in every program. Describe the problem before choosing a fix.

Quick answer

Save your work, restart, and test one simple task. Then check busy apps, startup activity and available storage. If only websites are slow, check the connection before blaming the computer.

Try opening a small document already stored on the laptop. If it opens promptly while several websites struggle, the difference is a clue. It does not prove the network is the only problem, but it helps narrow your next check. Our slow Wi-Fi guide covers that branch.

Restart and repeat one task

Save open documents, close apps normally and choose Restart. After the computer settles, open only the app needed for your test. Avoid launching your usual collection of tabs and programs immediately.

Pick a task you can repeat: open the same document, load the same known website or search the same folder. Note whether it improves. This creates a simple before-and-after comparison instead of a vague impression.

If one app is consistently the problem, check its official support guidance and updates before changing the entire computer. If everything is slow, look at the shared resources next.

See which apps are busy

In Windows, press Ctrl + Shift + Esc to open Task Manager. Review CPU, memory and disk activity while the slowdown is happening. Microsoft's performance troubleshooting guide explains these checks.

On a Mac, open Activity Monitor through Spotlight. Its CPU and Memory views help identify resource-heavy apps. Use Apple's Activity Monitor guide to interpret the controls.

Observe first. A high number during an update or export may be expected. Close an app you recognize normally before forcing it to quit, and save its work first. Do not stop unfamiliar system processes just because they appear near the top of a list.

Review storage and startup apps

In Windows, open Settings → System → Storage. In current macOS versions, open System Settings → General → Storage. Review the recommendations and files before deleting anything. Apple's slow Mac guide explains the storage and memory checks.

Start with files you recognize. Our Downloads organization guide offers a manageable routine for sorting installers, PDFs and duplicate-looking files. Keep a verified backup before removing important records.

In Windows Task Manager, review Startup apps and disable only optional programs you recognize and do not need immediately. For a work laptop, leave security and management tools in place and ask your IT team about unfamiliar items.

Separate normal maintenance from suspicious behavior

Install operating-system and app updates through their built-in update tools or official sources. In Windows, use Windows Update and Windows Security to check updates and run a scan. These are part of Microsoft's performance checks linked above.

A browser banner saying your computer has hundreds of viruses is not a performance diagnosis. Do not pay a supposed cleanup service simply because a web page says your device is infected. Our fake virus notification guide shows how to handle unwanted browser alerts.

If the laptop is managed by your employer, report the symptom and the time it happened. Installing an unapproved “speed booster” can create a second problem while leaving the first one unresolved.

Decide whether repair or an upgrade is worth investigating

Use the symptom to choose the next conversation
PatternUseful next step
Only one application strugglesCheck that application's requirements and support options.
Only websites are slowCompare the browser and internet connection.
Several apps struggle togetherReview memory, storage and background activity.
Crashes or repeated errors accompany the slowdownBack up important files and arrange a support assessment.

Before buying hardware, collect the model, software version, available storage and the task that runs slowly. A technician can then tell you whether the proposed upgrade is possible for that model and whether it addresses the observed problem.

A clear test is more valuable than a long list of cleanup apps. Keep a note of what changed and repeat the same task to see whether the change helped.
