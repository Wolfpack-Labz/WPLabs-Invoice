Printer Showing Offline in Windows 11? Fix Network, Queue, and Spooler Issues

If your printer is powered on but Windows says it is offline, use this methodical guide to find connection, queue, or driver problems.

Start here: identify the cause

A printer that says Offline may be powered on and perfectly functional. Windows can still lose track of its connection, keep an old address, or get stuck processing one failed print job. Start with the printer and network, then move toward Windows services and drivers.

Already tried the basics? This Windows-only guide expands on our Windows and Mac printer guide with network, queue and spooler diagnostics.

Before clearing the queue

Confirm the physical printer works. Restarting the spooler or clearing queued files can affect other users of a shared device.

Step 1: Check the printer's actual status

  1. Confirm the printer is on, has paper, and has no jam or error on its display.
  2. If possible, print a configuration or network status page directly from the printer's own menu. This tests the hardware without depending on Windows.
  3. Restart the printer: power it off, unplug it briefly if the manufacturer permits, then power it on.
  4. For USB printers, try a direct USB port and a different cable. For Wi-Fi printers, make sure the printer and computer are on networks that can communicate; a guest Wi-Fi network may isolate devices.

Diagnosis: If the printer cannot print its own internal test page, solve the hardware issue before changing Windows drivers.

Step 2: Check what Windows thinks is happening

Open Settings → Bluetooth & devices → Printers & scanners, select your printer, and choose Open print queue.

  • If there are old or stuck jobs, cancel them. Some versions of the queue window offer Cancel all.
  • If multiple copies of the same printer appear, verify you are sending the document to the correct one.
  • If Windows chose a different default printer, turn off Let Windows manage my default printer (if enabled) and set the intended printer as default.

Try printing a Windows test page from the printer's properties or settings. If Windows' test page succeeds, the original app or document may be the problem.

Step 3: Confirm the printer is reachable on the network

From the printer's network page or display, note its current IP address. On the Windows PC, open Command Prompt and run:

ping 192.168.1.50

Replace the example IP with the printer's real address. A reply suggests that the PC can reach that address. A failed ping is not proof the printer is disconnected, because some printers block ICMP. If the printer's IP changed recently, the Windows printer port or saved connection may be stale.

For shared printers managed by a company print server, ask IT to check server availability and permissions rather than changing the printer configuration on your own.

Step 4: Restart the Print Spooler service

The Print Spooler manages Windows print jobs. If it hangs, documents can remain stuck even when the printer is reachable.

  1. Press Win + R, enter services.msc, and press Enter.
  2. Find Print Spooler.
  3. Right-click it and select Restart.
  4. Reopen the print queue, then send a small test page.

If restart is blocked by policy or fails with an error, note the message and contact support rather than changing service permissions.

Step 5: Clear a queue that refuses to empty

Only do this if canceling jobs and restarting the service did not work. This will discard queued jobs for printers using this PC's local spooler, so inform other affected users on a shared computer.

  1. Open services.msc and Stop the Print Spooler service.
  2. In File Explorer, navigate to C:\Windows\System32\spool\PRINTERS. Administrator permission may be required.
  3. Delete the files inside PRINTERS, not the folder itself. If your system is managed or the directory is inaccessible, stop and contact IT.
  4. Return to Services and Start the Print Spooler.
  5. Open the printer queue again and print a small test document.

This clears pending jobs but does not repair a hardware fault, an incorrect network address, or an incompatible driver.

Step 6: Update or reinstall the correct printer driver

  1. In Printers & scanners, select the problem printer.
  2. Check for a driver update through Windows Update or the printer manufacturer's official support site.
  3. If the printer remains unavailable, remove the printer device from Windows and use Add device to set it up again. Keep the printer's model number and network details handy.
  4. On company print servers or multifunction systems with custom scanning features, coordinate with IT first; removing a shared queue can affect managed settings.

Avoid third-party “driver update” download sites. They can install the wrong package or bundle unwanted software.

Step 7: Differentiate Windows from the application

If a Windows test page works but printing from Word, a browser, or another app fails, try another document and another application. Review paper size, selected printer, and app updates. The fix may be in the application, not Windows networking.

How to confirm the problem is fixed

Print a Windows test page, then a real document. Check that jobs leave the queue and that the printer remains available after a PC restart. For wireless printers that frequently change IP address, consider a router-side DHCP reservation if your network administrator supports it.

Frequently asked questions

Why does Windows say Offline when my printer is on?

Windows cannot confirm communication with the selected printer connection. A stale address, blocked network path, failed spooler, or stuck queue can cause this status.

Does restarting Print Spooler delete my documents?

Restarting the service alone does not intentionally delete your saved documents. Clearing its spool folder removes waiting print jobs, not the original source files.

Should I disable Windows Firewall to test printing?

No. Avoid disabling security protections broadly. On managed networks, ask IT to diagnose the specific allowed printing protocol or port.
