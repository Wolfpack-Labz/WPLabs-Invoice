Windows 11 Connected to Wi-Fi but No Internet? How to Find and Fix the Cause

Your laptop shows a Wi-Fi connection, but websites will not load. Use these checks to tell whether the problem is your PC, router, DNS, or internet provider.

Start here: identify the cause

A Wi-Fi symbol only proves that your computer has connected to a wireless network. It does not prove that your router can reach the internet or that Windows can translate website names into IP addresses. The best fix depends on which part of the connection failed.

This Windows 11 deep dive goes beyond our general Wi-Fi connection guide with DHCP, gateway and DNS tests.

Quick diagnosis

Compare another device on the same Wi-Fi before resetting network settings. Corporate VPNs and managed network configurations may require IT approval.

Before you change anything: isolate the problem

  1. On the affected PC, try two unrelated websites, such as a news site and a search engine. If only one site fails, investigate that website or browser first.
  2. Open a website on your phone while connected to the same Wi-Fi. Then switch your phone to cellular data and try again.
  3. If every device fails on Wi-Fi, check your router's internet status and your provider's outage information. If only one Windows computer fails, continue below.
  4. If you use a company VPN, managed laptop, or custom DNS configuration, contact IT before resetting network settings. These fixes can disconnect remote access.

Quick interpretation: Phone works on Wi-Fi but laptop fails = likely a PC-level issue. Both fail on Wi-Fi but cellular works = likely router or internet service. One website fails everywhere = likely site-specific.

Step 1: Restart the connection without resetting the computer

  1. Go to Settings → Network & internet → Wi-Fi.
  2. Turn Wi-Fi off, wait a few seconds, and turn it on again.
  3. Reconnect to your normal network. If the network requires a captive portal (hotel, café, campus), open a browser and complete its sign-in page.
  4. Restart your router only if you control it and other devices are affected; avoid rebooting shared workplace equipment.

Test the same websites again. If they still fail, determine whether Windows received a usable network address.

Step 2: Inspect your IP address and gateway

Open Windows Terminal or Command Prompt and run:

ipconfig /all

Find the active Wi-Fi adapter. Look for IPv4 Address, Default Gateway, DHCP Enabled, and DNS Servers.

  • An address starting with 169.254. often means Windows did not receive an IPv4 address from DHCP.
  • A missing default gateway often indicates that the PC cannot reach the router normally.
  • A valid address and gateway with broken website names may point toward DNS, but additional tests are needed.

If your home network uses DHCP and the address looks wrong, open Command Prompt as administrator and run:

ipconfig /release
ipconfig /renew

These commands briefly drop the adapter's IPv4 lease. Do not run them during a remote support session or on a managed computer without approval. If renewal fails, check the router's DHCP settings or try another Wi-Fi network.

Step 3: Test the router and DNS separately

From Command Prompt, run:

ping 192.168.1.1
nslookup example.com

Replace 192.168.1.1 with the Default Gateway listed in your own ipconfig output. A successful gateway response suggests that the PC can reach the router. Some routers block ping, so failure isn't conclusive.

nslookup tests name resolution. If it returns timeouts or a server error while other connectivity works, your configured DNS server may be unavailable. Corporate and VPN DNS must be handled by your IT administrator.

Step 4: Clear cached DNS answers

Open Command Prompt as administrator and run:

ipconfig /flushdns

This clears cached name-resolution results; it does not reset your router or erase personal files. Close and reopen your browser, then retry the affected sites. If DNS still fails, check the network's configured DNS servers rather than repeatedly clearing the cache.

Step 5: Check browser, VPN, and proxy configuration

  1. Try the same page in a private window or a different browser.
  2. Under Settings → Network & internet → Proxy, look for a manual proxy. Do not disable a required workplace proxy; instead confirm it matches your organization's instructions.
  3. If you are using a personal VPN, temporarily disconnect it and retest. Reconnect after diagnosis.
  4. Check the computer's date and time. Incorrect settings can make secure websites appear broken even when internet access exists.

If the connection works in another browser, concentrate on extensions and browser settings before changing Windows networking.

Step 6: Update the wireless adapter or use Windows troubleshooting

  1. Search for Get Help and run the network/internet troubleshooter, or go to Settings → System → Troubleshoot.
  2. Open Device Manager → Network adapters, right-click your Wi-Fi adapter, and choose Update driver.
  3. If the problem began immediately after a driver change, check the adapter's Properties → Driver → Roll Back Driver option when available.
  4. Get drivers only from Windows Update or the PC/network-adapter manufacturer's official website.

Step 7: Network reset is the last resort

If the PC alone still cannot connect and none of the checks identified a fix, go to Settings → Network & internet → Advanced network settings → Network reset. Windows will remove and reinstall network adapters and reset related settings after a restart. You may need to reinstall VPN software or reconfigure virtual adapters afterward.

How to confirm the problem is fixed

Open two HTTPS websites, confirm that name lookups work, and reconnect any VPN that you normally use. Test again after the next restart. If your devices continue losing connectivity together, focus on the router or ISP rather than repeatedly resetting Windows.

Frequently asked questions

Why does Wi-Fi say “Connected” if I have no internet?

Because Wi-Fi connection status describes the link to your local wireless network. DNS, router routing, ISP service, and browser connectivity are separate stages.

Will flushing DNS delete my files?

No. ipconfig /flushdns clears a Windows DNS cache; it does not touch documents or photos.

Should I immediately change my DNS to a public provider?

Not necessarily. Diagnose first. A public DNS service can break organization-only domains, parental controls, or VPN-based name resolution.
