Windows 11 Update Keeps Failing? Fix Download and Installation Errors Step by Step

An update repeatedly fails, gets stuck, or rolls back. Work from basic checks to system-file repairs and a safe reset of the update download cache.

Start here: identify the cause

Windows Update failures are frustrating because the same symptom—an update that never finishes—can come from very different causes. Insufficient space, an interrupted download, a damaged system component, or a driver conflict can all prevent an update from installing.

The safest troubleshooting order is identify the failed update, run the built-in troubleshooter, repair Windows files, and only then clear the update cache.

Before changing system files

Back up important data, connect to power and record the failed KB number and error code before running repair tools.

Before you begin

  • Back up important files and connect a laptop to power. System repair commands are intended to preserve personal files, but backups are still essential.
  • If the device is managed by work or school, coordinate with IT before modifying update services.
  • Note the failed update's KB number and error code. Go to Settings → Windows Update → Update history to find them; those details make further troubleshooting more precise.
  • Restart once if Windows says a restart is pending.

Step 1: Check storage, connection, and attached devices

  1. Open Settings → System → Storage. Make room if your system drive is nearly full. Large feature updates may need substantially more free space than small cumulative updates.
  2. Verify your internet connection is stable and that any metered-network setting isn't intentionally restricting downloads.
  3. Disconnect nonessential USB drives, docks, and peripherals before a major upgrade—especially if the failure began with a hardware change.
  4. Open Settings → Windows Update and try Check for updates again.

If the same KB continues failing, move to diagnostics rather than repeating the installation indefinitely.

Step 2: Run the Windows Update troubleshooter

  1. Open Start → Get Help and search for the Windows Update troubleshooter. Alternatively, look under Settings → System → Troubleshoot → Other troubleshooters where available.
  2. Allow the tool to perform checks and apply suggested fixes.
  3. Restart if requested, then retry the failed update.

If the tool reports a specific error code, record it for a focused search in Microsoft's support documentation.

Step 3: Repair the Windows component store using DISM

A damaged component store can prevent updates and repairs from completing. Search for Command Prompt, choose Run as administrator, and run:

DISM.exe /Online /Cleanup-Image /RestoreHealth

Allow the operation to finish. DISM can use Windows Update as a repair source, so network access may be required. If you see a source-file or repair-source error, don't copy an arbitrary repair image from the internet; use official matching Windows installation media or contact IT.

Step 4: Check protected system files with SFC

After DISM completes, run this in the same administrator Command Prompt:

sfc /scannow

Do not close the window until verification reaches 100%.

  • No integrity violations: Windows did not detect protected-file corruption.
  • Found corrupt files and successfully repaired them: Restart, then attempt Windows Update again.
  • Found corrupt files but could not fix some: Follow Microsoft's SFC guidance or escalate for an offline repair assessment.

DISM and SFC are different tools: DISM repairs the component store; SFC checks protected system files against trusted copies.

Step 5: Clear the update download cache if the same download fails

Do this only if the previous steps did not work. The update download cache is not your personal document folder, but resetting it can cause Windows to download update packages again and may affect displayed local update history.

  1. Press Win + R, enter services.msc, and press Enter.
  2. Find Windows Update, right-click it, and choose Stop. If Windows says it cannot stop the service, do not force the deletion; seek managed-device support.
  3. Open File Explorer and enter C:\Windows\SoftwareDistribution\Download in the address bar.
  4. Delete the contents of the Download folder only, not the folder itself. If files are locked, skip them rather than forcing access.
  5. Return to Services and Start Windows Update.
  6. Restart the PC and retry the update. Windows can download fresh packages.

Avoid deleting unrelated system directories, registry keys, or driver packages from online scripts.

Step 6: Look for a repeating driver or compatibility problem

If a feature upgrade rolls back but regular security updates succeed, check Settings → Windows Update → Update history and any on-screen compatibility warning. Update relevant drivers from the device manufacturer's official site. Do not install generic “driver fixer” utilities.

If one particular update still fails, search its exact KB number + error code on Microsoft's support website before trying reinstall or reset options. A failure such as insufficient space requires a different solution from a corrupted servicing component.

Confirm the update installed successfully

Return to Settings → Windows Update → Update history, verify the KB is listed under successful updates, and restart as prompted. Check that your essential applications still open. If the error persists, provide your administrator or support team the KB number, error code, Windows version (winver), and the results of DISM and SFC.

Frequently asked questions

Will SFC or DISM remove my personal files?

These utilities are designed to repair Windows components, not delete personal documents. Backups are still recommended before system-level troubleshooting.

Why does an update fail at the same percentage?

The visible percentage does not reveal the root cause by itself. Use the error code and update history, not the percentage alone.

Should I reset or reinstall Windows immediately?

No. Diagnose the specific update, run the troubleshooter, and repair the component store first. Reinstallation is a more disruptive last step.
