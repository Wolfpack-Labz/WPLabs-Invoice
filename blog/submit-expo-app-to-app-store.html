How to submit an Expo app to the App Store

A finished app needs a production build, an upload to App Store Connect, and a separate submission for Apple’s review.

By Wolfpack Labs · 5 min read
In this guideGet the project readyBuild the production appUpload, then testComplete the review submissionKeep the official guides nearby

Get the project ready

You need an Apple Developer account and a stable iOS bundle identifier in your app configuration. Keep that identifier consistent with the App Store Connect app record.

Before building, review your production configuration, privacy details, support links, screenshots, and any purchases your app offers. Use a fresh account to test the experience a reviewer will see.

Build the production app

Configure EAS Build for the project using Expo’s setup guide. With a production profile in place, create an iOS build:

eas build --platform ios --profile production

Review the build result before continuing. A successful build shows the app compiled; it does not prove every customer workflow works.

Upload, then test

EAS Submit can upload the build to App Store Connect:

eas submit --platform ios

Wait for Apple to process the build, then use TestFlight to test the app on a device. Uploading is separate from releasing it publicly.

Complete the review submission

In App Store Connect, select the processed build for the app version and complete the required version information. Supply review access and any instructions needed to reach the app’s main features.

Use Apple’s current submission checklist to complete the review submission. The exact requirements depend on the app and may change, so consult the official documentation before each release.
