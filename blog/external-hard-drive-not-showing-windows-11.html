External Hard Drive Not Showing Up in Windows 11? Diagnose It Without Losing Files

USB drive missing from File Explorer? Learn how to check ports, Disk Management, drive letters, and RAW partitions without risking your data.

Start here: identify the cause

You plug in an external SSD, hard drive, or USB flash drive, hear the connection sound, and then see nothing in File Explorer. That does not automatically mean the drive is empty or broken. Windows may detect the hardware without assigning a drive letter, or it may be unable to recognize the file system.

Critical rule: If the drive once contained files, do not initialize, format, delete partitions, or create a new volume just to make it appear. Those actions can destroy access to existing data.

Protect your data first

Never initialize, format or create a new volume on a disk that may still contain files you need. Stop repeated tests if hardware appears to be failing.

Step 1: Rule out the simplest hardware causes

  1. Disconnect the drive safely if Windows offers an eject option; otherwise close any applications using it first.
  2. Reconnect it directly to a different USB port, not through an unpowered hub.
  3. Try a known-good data-capable USB cable. Some cables charge devices but do not support data transfer properly.
  4. For desktop external drives with separate power adapters, verify the power adapter is correct and working.
  5. If the drive makes repeated clicking noises, disconnects unexpectedly, or becomes unusually hot, stop repeated testing and consider professional recovery.

If possible, test the drive on a second computer. That can help distinguish an issue with the drive from one with the original PC.

Step 2: Check whether Windows sees the device at all

  1. Right-click Start → Device Manager.
  2. Expand Disk drives and Universal Serial Bus controllers.
  3. Look for your drive model, an unknown USB device, or an icon with a warning symbol.
  4. Open the device's Properties → General tab and record any device-status error code.
  5. Use Action → Scan for hardware changes after reconnecting the drive.

If the device appears only intermittently, suspect cable, power, USB controller, or physical drive problems before attempting file-system changes.

Step 3: Open Disk Management and interpret what you see

Press Win + R, enter:

diskmgmt.msc

Locate the external disk by capacity and model, not by assuming it is “Disk 1” or “Disk 2.” Compare the result with these common states:

Disk Management status What it usually means Safe next action
Online, Healthy, partition present, no letter Windows sees a volume but File Explorer has no mount letter Assign an unused drive letter
Offline Windows detected a disk but has not brought it online Assess why; on personal, non-shared removable disks, bringing it online may be appropriate
RAW Windows cannot identify a usable supported file system Do not format if files matter; investigate recovery or compatibility
Not initialized / Unallocated No usable partition layout is visible to Windows Do not initialize or create a volume if the drive previously held files
Missing from Disk Management Windows cannot currently present the drive Return to cable, power, port, and hardware diagnosis

A disk formatted for macOS or Linux may appear unreadable in Windows without compatible software. Encryption, including BitLocker, can also require an unlock or recovery key.

Step 4: Assign a drive letter only when a valid partition exists

If the external drive is Online, has a healthy existing partition, and simply lacks a drive letter:

  1. Right-click that volume in Disk Management.
  2. Select Change Drive Letter and Paths.
  3. Choose Add (if none exists), select an unused letter, and confirm.
  4. Open File Explorer and check This PC.

Do not change your Windows system-drive letter, EFI or Recovery partitions, or letters that important software relies on. The assignment option may be unavailable when Windows cannot mount the volume.

Step 5: Use a read-only PowerShell inventory for clarity

If you're comfortable with Windows administration, open PowerShell and run:

Get-Disk | Format-Table Number, FriendlyName, OperationalStatus, PartitionStyle, Size

This command displays disk information; it does not format or initialize anything. Match the size and model with what you saw in Disk Management. Avoid copying initialization commands from forum posts unless you are certain the disk is new and empty.

Step 6: What to do when the partition says RAW or unallocated

If the disk previously contained important files, stop here. Don't run format, clean, Initialize-Disk, or New Simple Volume. Consider a verified backup, manufacturer support, or a reputable data-recovery specialist. Continuing to write to the drive can complicate recovery.

For a brand-new, confirmed empty drive, Windows' Disk Management can initialize and create a volume. That is a setup workflow, not a recovery fix, and is outside the steps for preserving existing data.

Step 7: Check encryption and file-system compatibility

If a drive is visible but inaccessible, confirm how it was previously used. BitLocker-protected volumes require the appropriate unlock method. macOS APFS and certain Linux file systems are not natively readable through ordinary Windows File Explorer in the same way as NTFS or exFAT. Don't assume the disk needs formatting just because Windows prompts you to format it.

Confirm the drive is healthy

Once the files appear, copy one unimportant file to a safe location only if the drive seems stable, and check that your important files are backed up. If the disk repeatedly disconnects or develops errors, prioritize data recovery over further troubleshooting.

Frequently asked questions

Why is the drive in Device Manager but not File Explorer?

Device Manager identifies hardware. File Explorer generally needs a mountable file system and assigned drive path to display the contents.

Is assigning a drive letter safe?

Adding a letter to an existing healthy data volume is usually non-destructive. Still, verify the correct volume and avoid changing letters used by applications.

Should I click “Format disk” when Windows asks?

Not if the drive previously stored files you need. A format prompt can indicate an unsupported or damaged file system, not an empty drive.
